What is doing the teaching. Stack frames are nested, not stacked cards — a call stack is nested lifetimes, so depth reads as indentation and recursion takes a visible shape; a returned frame is gone, not greyed, because that is what returning means in C. Heap blocks float in address order with plausible addresses. Pointer arrows live only in the whitespace between the columns, colored by origin, fanned into lanes so two pointers to one block run parallel. The moment to watch: step 13 — head = make_node(9) overwrites the only pointer into the old list, and two blocks quietly acquire their leaked? tags. That is a memory leak, seen rather than told.
